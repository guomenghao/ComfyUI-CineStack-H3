# CineStack / 影栈的演进方向

平台品牌：CineStack / 影栈。未来应用名称：CineStack Studio / 影栈影视工作台。
当前插件与仓库：ComfyUI-CineStack-H3；Registry 包标识：cinestack-h3。

当前提供 H3 多段生成、固定分段 seed 与严格缓存精修。

后续候选阶段（尚未实现，不作为当前功能承诺）：

1. 本地项目管理：剧本、人物/场景、素材版本、镜头计划及生成记录。
2. 自动化执行：任务队列、依赖关系、失败恢复、人工确认节点、模型适配。
3. 后期制作：采用片段、剪辑时间轴、对白/声音、字幕及最终成片导出。
4. 独立桌面工作台：以 ComfyUI 为生成后端，提供面向影视制作的完整应用。

未来平台可使用独立 `CineStack` 仓库；当前插件保持单一 H3 模块边界。
